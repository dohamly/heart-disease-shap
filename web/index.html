Why did the model make this prediction?

Valeurs SHAP : contribution de chaque variable à la prédiction de ce patient, calculée à partir des coefficients réels du modèle (somme exacte : valeur de base + contributions = sortie du modèle).

Lance une prédiction dans l'onglet Prediction pour voir l'explication ici.

Lire une explication SHAP

  • On part du patient moyen du jeu d'entraînement, puis chaque variable déplace la probabilité estimée vers le haut (rouge, « maladie ») ou vers le bas (vert, « sain »).
  • Les valeurs sont des log-odds : plus elles sont grandes en valeur absolue, plus l'effet est fort. La colonne de droite traduit le cumul en probabilité.
  • Une variable catégorielle (ex. type de douleur thoracique) est résumée en une seule barre : on additionne les contributions de ses colonnes encodées.
SHAP explique le comportement du modèle, pas une relation causale médicale. Une variable qui augmente la probabilité estimée n'est pas pour autant une cause de la maladie. Projet académique : ce n'est pas un outil de diagnostic médical et il ne doit pas servir à une décision clinique.

About the Project

Heart Disease Prediction + Explainable AI is a machine learning project designed to predict heart disease risk while making model decisions more understandable through SHAP explainability. It was developed as part of a university AI portfolio to demonstrate end-to-end proficiency in data science, model development, and responsible AI.

Dataset

The Cleveland Heart Disease dataset from the UCI Machine Learning Repository contains 303 patient records with 13 clinical attributes. It is one of the most widely used benchmarks for cardiovascular disease classification research.

Machine Learning

Three classifiers were compared with nested 5-fold stratified cross-validation (hyperparameters tuned on the inner loop only). Their scores are statistically indistinguishable, so the simplest one, Logistic Regression, was selected (F1 80.4%, ROC-AUC 0.906).

Explainable AI

SHAP (SHapley Additive exPlanations) provides exact feature-level attribution for every prediction. Both global summaries (mean absolute SHAP across the training set) and local explanations (per-patient contribution breakdowns) are available.
